# LLM Provider File Map

This document tracks Pi `packages/ai/src` against Gi `gi-llm-provider`. It is a
working file/function parity audit, not a completion claim.

## Status Legend

- `direct`: Gi has a same-purpose file/function implementation.
- `split`: Pi's file is represented by multiple Go files.
- `consolidated`: Pi's small file is folded into a larger Go file.
- `go-native`: Pi's Node/TS-specific surface is represented by Go-native code.
- `partial`: Gi has some equivalent behavior, but the file/function audit is not
  complete or a Pi feature is missing.
- `gap`: no current Gi equivalent.

## Pi v0.82.0 Provider Factory and Catalog Files

`providers/*.ts` files small factories. Gi keeps transport files focused and
consolidates the factory declarations into a typed table. Each call constructs
fresh provider/runtime state; the generated catalog is frozen separately.

## Remaining LLM Provider Gaps

- All built-in subscription providers now have provider-owned OAuth defaults.
  Anthropic and OpenAI Codex share a Go-native callback/manual-code state
  boundary; Codex additionally reuses the typed RFC 8628 device poller.
  Application loaders remain optional overrides, and `openai-codex` is
  configurable through `BuiltinModels` without application registration.
- Radius catalog, browser/device OAuth, refresh-token rotation, request auth,
  and `pi-messages` request/stream behavior are implemented. The provider owns
  protocol and callback state while the caller supplies only `AuthInteraction`.
- The Google Vertex API-key/ADC login contract and API provider are registered.
  Express API-key streaming and ADC streaming are complete through caller-owned
  authorization, an injected token provider, or the official Go OAuth2 default
  credential chain. Token refresh is coalesced per request configuration.
- Codex websocket/cache transport is implemented with a Go-owned connection
  lease, session continuation state, backend-age rotation, idle cleanup, and
  pre-stream SSE fallback. SSE requests are level-3 zstd-compressed once and
  reuse immutable bytes across retries; WebSocket frames intentionally retain
  uncompressed JSON.
- Bedrock now defaults to AWS SDK v2 ConverseStream with SigV4, bearer-token,
  profile/static/default-chain credentials, scoped proxy/HTTP configuration,
  pre-signing custom headers, and response metadata. The provider-neutral
  request/event boundary remains injectable and is the deterministic test seam;
  credentialed live probes remain intentionally outside the default suite.
- `cli.ts` is not mirrored as a standalone provider package CLI. Gi login flows
  are implemented in `gi-coding-agent`; this may be an accepted abstraction move,
  but it still needs an explicit scope decision.
