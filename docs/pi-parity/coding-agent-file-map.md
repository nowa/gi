# Coding Agent File Map

This document tracks Pi `packages/coding-agent/src` against Gi
`gi-coding-agent`, `cmd/gi`, and `protocol`. It is a working source/function
audit, not a completion claim.

## Status Legend

- `direct`: Gi has a same-purpose implementation and test evidence.
- `split`: Pi's file is represented by multiple Go files.
- `consolidated`: Pi's small files are folded into a larger Go file.
- `protocol`: Pi's in-process TypeScript extension surface is represented by
  the Gi RPC/ViewTree/package protocol.
- `go-native`: Pi's Node/Bun-specific file maps to Go-native behavior.
- `partial`: Gi has user-facing behavior, but function-level parity remains
  under audit.
- `gap`: no current Gi equivalent.
- `not-applicable`: intentionally excluded from Gi.
